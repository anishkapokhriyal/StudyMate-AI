# StudyMate AI

A Streamlit learning assistant with Gemini-powered tutoring, interactive quizzes, revision notes, weekly study planning, and a local SQLite progress tracker.

## Setup

1. Install dependencies: `py -m pip install -r requirements.txt`
2. Create `.streamlit/secrets.toml` with `GEMINI_API_KEY = "your-key"`.
3. Run: `py -m streamlit run app.py`

Keep `.streamlit/secrets.toml` private. Never commit API keys.
